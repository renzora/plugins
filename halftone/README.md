# Halftone

A halftone dot screen: brightness becomes dot size on a rotated grid, the way newsprint and comic books reproduce tone.

**Add it:** `+ Add Entity → Post Process → Halftone`, or Add Component on an entity you already have.

**Settings:** `dot_size`, `angle`, `intensity`

**Shader:** `src/halftone.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
