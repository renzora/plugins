# Pool Water

Still water for pools, ponds and tanks: refraction through the surface, depth-tinted colour, animated caustics on what lies beneath, and a height-field ripple simulation that reacts rather than looping.

For open ocean use the **Water** plugin instead: this one is a bounded surface with a floor, not a wave spectrum.

**Add it:** `+ Add Entity → Rendering → Pool Water`, then size the surface with its Transform.

**Settings:** water level, IOR, Fresnel minimum, refraction strength, caustic intensity, deep / shallow / foam colour, max depth, foam depth, damping, wave speed, height scale.

**Scope:** Runtime (editor viewport and shipped game).
