# Swirl

Twists the frame around its centre, falling off to nothing outside `radius`.

The centre is fixed at the middle of the screen. **Radial Blur** is the effect in this set with a movable one.

**Add it:** `+ Add Entity → Post Process → Swirl`, or Add Component on an entity you already have.

**Settings:** `angle`, `radius`

**Shader:** `src/swirl.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
