# Emboss

Emboss: the picture is turned into a relief of light and shadow along its edges, as if stamped into metal or paper.

**Add it:** `+ Add Entity → Post Process → Emboss`, or Add Component on an entity you already have.

**Settings:** `strength`, `mix_amount`

**Shader:** `src/emboss.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
