# Matrix Rain

Falling-code rain over the frame: columns of glyphs descending with a glowing head and a fading trail.

**Add it:** `+ Add Entity → Post Process → Matrix Rain`, or Add Component on an entity you already have.

**Settings:** `speed`, `density`, `glow`, `trail_length`

**Shader:** `src/matrix.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
