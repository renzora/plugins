# Sharpen

Sharpens the frame by boosting local contrast. Useful after TAA or an upscale, both of which soften the picture.

**Add it:** `+ Add Entity → Post Process → Sharpen`, or Add Component on an entity you already have.

**Settings:** `strength`

**Shader:** `src/sharpen.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
