# Color Grading

Whole-frame colour correction: exposure and contrast, saturation, gamma, and a temperature/tint pair for warming or cooling the picture.

**Add it:** `+ Add Entity → Post Process → Color Grading`, or Add Component on an entity you already have.

**Settings:** `brightness`, `contrast`, `saturation`, `gamma`, `temperature`, `tint`

**Shader:** `src/color_grading.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
