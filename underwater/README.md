# Underwater

Submerged look: a blue-green tint, a rolling refraction, and caustic light playing over the frame. Switch it on when the camera goes below the surface.

**Add it:** `+ Add Entity → Post Process → Underwater`, or Add Component on an entity you already have.

**Settings:** `distortion`, `tint_strength`, `wave_speed`, `wave_scale`

**Shader:** `src/underwater.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
