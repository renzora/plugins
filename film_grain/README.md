# Film Grain

Animated film grain over the finished frame. `time` advances on its own, so the grain moves rather than sitting still as a fixed pattern.

**Add it:** `+ Add Entity → Post Process → Film Grain`, or Add Component on an entity you already have.

**Settings:** `intensity`, `grain_size`

**Shader:** `src/film_grain.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
