# Night Vision

A night-vision scope: the frame is amplified, tinted green, and given the noise and scanlines of an image intensifier.

**Add it:** `+ Add Entity → Post Process → Night Vision`, or Add Component on an entity you already have.

**Settings:** `intensity`, `noise_amount`, `scanline_amount`, `color_amplification`

**Shader:** `src/night_vision.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
