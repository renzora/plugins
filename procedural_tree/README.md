# Procedural Tree

Seeded branch and leaf meshes, generated on demand. Adding a `Tree` builds the branch mesh on that entity plus a child entity holding the leaves; change a setting and it regenerates.

**Add it:** `+ Add Entity → General → Procedural Tree`, or Add Component → Procedural Tree on an entity you already have.

**Settings:** tree type, leaf count, leaf size, trunk radius, and a Regenerate button for a fresh seed.

**Tip:** tag the tree root with **Wind Sway** (the Wind plugin) and the branches move with the world wind.

**Scope:** Runtime (editor viewport and shipped game).
