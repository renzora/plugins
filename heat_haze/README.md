# Heat Haze

The shimmer of hot air: a scrolling distortion that rises up the frame. `time` advances on its own.

**Add it:** `+ Add Entity → Post Process → Heat Haze`, or Add Component on an entity you already have.

**Settings:** `intensity`, `speed`, `scale`

**Shader:** `src/heat_haze.wgsl` · **Scope:** Runtime (editor viewport and shipped game)
